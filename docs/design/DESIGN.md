# DESIGN.md — jobible_ 개인 홈페이지

> 이 프로젝트의 디자인 기준 문서. UI를 만들거나 고치기 전에 반드시 읽는다.
> 기반: getdesign.md의 Airbnb 분석(`airbnb-reference.DESIGN.md`)을 참고하되, 아래 **프로젝트 오버라이드가 항상 우선**한다.
> 시각 기준: `mockup-desktop.html` (확정 C안, 1280px). 브라우저로 열어서 비교한다.

## 1. 한 줄 요약

흰 바탕에 먹색 글씨, 친근한 둥근 모서리. 색은 두 가지만 절제해서 쓴다. 작은 포인트는 **코랄**, 큰 글씨 강조는 **플럼**이다. 화려한 효과 없이 "실제로 쓰이는 서비스"를 담백하게 보여준다.

## 2. 프로젝트 오버라이드 (Airbnb 원본과 다른 점)

| 항목 | Airbnb 원본 | 이 프로젝트 |
|---|---|---|
| 폰트 | Airbnb Cereal VF | **Pretendard** (한글·영문 통일) |
| 주 버튼 배경 | `#ff385c` | **`#E00B41`** (흰 글씨 대비 4.5:1 확보) |
| 큰 글씨 강조 | 없음 | **플럼 `#92174D`** (Airbnb Plus 계열) |
| 디스플레이 크기 | 22–28px | Hero 제목 52px (포트폴리오라 한 단계 키움) |

| 로고·아이콘·일러스트 | Airbnb 고유 자산 | **사용 금지.** 브랜드 복제 아님, 규칙만 참고 |

### 색 사용 규칙 (중요)
- **강조 지점은 정해진 곳에만 쓴다.** 코랄: 상태 점, 로고 원, Hero 배지, 바로가기 원형 버튼, 이메일 복사 버튼. 플럼: Hero 제목의 "실제로 쓰이는" 구절, About 통계 숫자 3개.
- 섹션 배경을 코랄이나 플럼으로 칠하지 않는다. 카드에 색 테두리를 두르지 않는다. 버튼을 더 늘리지 않는다. 강하면 싸 보인다는 것이 오너의 명확한 피드백이다.
- 그라데이션 금지.

## 5. 모양·간격·그림자

- 모서리: 스크린샷 카드 20px, 스크린샷 안 패널 14px, 보관함 카드 14px, About 호스트 카드 24px, 배지·바로가기·nav 링크 완전 원형(999px), 사각 버튼 8px.
- 간격 기준: 4px 단위. 섹션 사이 96–104px, 카드 사이 20–28px, 좌우 여백 80px(데스크톱).
- 컨테이너: 최대 1120px(1280 - 80×2), 가운데 정렬.
- 그림자: 매우 옅게, 떠 있는 요소에만.
  - 바로가기 바: `0 0 0 1px rgba(0,0,0,.02), 0 2px 6px rgba(0,0,0,.04), 0 6px 16px rgba(0,0,0,.08)`
  - 스크린샷 위 배지: `0 2px 6px rgba(0,0,0,.08)`
  - About 호스트 카드: `0 6px 24px rgba(0,0,0,.12)`
  - 그 외 카드는 그림자 없음.

## 6. 섹션별 명세

### Nav (높이 80px, 하단 1px `hairline-soft`)
- 왼쪽: 코랄 원(28px, 흰 "j") + 워드마크 `jobible_` (21px/700, `coral-strong`)
- 오른쪽: 서비스 · 보관함 · About 앵커 링크 (15px/600, 원형 hover 배경 `surface-soft`)

### Hero (가운데 정렬)
1. 배지: `coral-tint` 배경, 코랄 점 + "3개 서비스 운영 중" (`coral-ink`)
2. h1: "작지만, **실제로 쓰이는**(플럼) / 서비스를 만듭니다"
3. 부제: 기업 AI 에이전트를 설계하는 박준형이 교회와 가족, 일상의 작은 문제를 풀려고 퇴근 후 만들어 온 jobible_ 시리즈입니다. (최대폭 620px, `muted`)
4. 바로가기 바 (높이 72px, 원형, 옅은 그림자): 세 칸 "교회 / 시설·차량 예약", "제자훈련 / 참고 자료", "시니어 / 매일 좋은 글귀" + 오른쪽 `coral-strong` 원형 화살표 버튼(52px). 각 칸은 해당 서비스 카드로 이동하는 앵커.

### 운영 중인 서비스 (`#services`)
- 머리: 왼쪽 h2 "운영 중인 서비스", 오른쪽 "필요한 사람 곁에서 시작했습니다" (`muted`)
- 3열 그리드, 카드에 테두리 없음 (Airbnb 숙소 카드 방식)
  - 스크린샷 영역: 높이 300px, 모서리 20px, 왼쪽 위에 흰 배지 (onspot "교회에서 실제 사용 중", way "제자훈련반 참고", goodday "시니어를 위한 글귀")
  - 제목 줄: 서비스명(h3) + 오른쪽 코랄 점 "운영 중"
  - 메타: "낙원제일교회 · Next.js, Turso" 형식 (`muted`)
  - 설명 1–2줄 (`body`)
  - 카드 전체가 서비스 URL 링크 (새 탭)

### 지난 실험들 (`#archive`)
- h2(22px) + 2열 가로 카드 (`surface-soft` 배경, 모서리 14px)
- 카드: 56px 썸네일 자리 + 이름/설명 + 오른쪽 "휴식 중" (`muted-soft`)
- 운영 중인 서비스보다 시각적 위계를 확실히 낮춘다.

### About (`#about`)
- 왼쪽(420px): 호스트 카드. 원형 아바타(104px, 먹색 배경, 흰 "준") + 이름 + "AX Team Lead" / 오른쪽 통계 3줄: **21년+** IT 경력, **3** 운영 중 서비스, **5** jobible_ 시리즈 (숫자는 플럼)
- 오른쪽: h2 "만든 사람을 소개합니다" + 소개 문단 + 이메일/LinkedIn 텍스트 + 버튼 두 개 ("이메일 주소 복사" `coral-strong` 채움, "LinkedIn 열기" 먹색 테두리)
- 이메일 복사: `navigator.clipboard.writeText` → 성공 시 버튼 문구 "복사됨"으로 1.5초 변경, 실패 시 텍스트 선택으로 대체

### Footer
- `surface-soft` 배경, 상단 1px `hairline`
- 왼쪽 "© 2026 박준형 · jobible_", 오른쪽 서비스 · About 링크

## 7. 반응형 (모바일은 시안 없음, 아래 규칙으로 구현)

| 구간 | 변경 |
|---|---|
| ≥1024px | 시안 그대로 |
| 768–1023px | 좌우 여백 40px, 서비스 2열, About 세로 쌓기 |
| ≤767px | 좌우 여백 20px, h1 34px, 섹션 간격 72px |

모바일(≤767px) 세부:
- Nav: 링크를 햄버거 버튼(44×44)으로 접는다.
- Hero 바로가기 바: 가로 원형 바 대신 **세로로 쌓인 카드 한 장**(모서리 20px, 세 행을 구분선으로 나눔) + 아래에 `coral-strong` 전체폭 버튼 "서비스 둘러보기".
- 서비스·보관함: 1열. 스크린샷 높이 220px.
- About: 호스트 카드 → 소개 → 버튼 순서, 버튼은 전체폭.
- 터치 대상 최소 44px.

## 8. 접근성
- 흰 글씨 버튼은 `#E00B41` 이상으로 어둡게 (코랄 `#FF385C` 위 흰 글씨 금지).
- 링크·버튼은 실제 `<a>`, `<button>`. 키보드 포커스 표시 (`outline: 2px solid #222; outline-offset: 2px`).
- 스크린샷 `alt`에 화면 설명.
- `prefers-reduced-motion` 존중 (스크롤 애니메이션 쓰지 않는 것이 기본).
